# Rainwater Flow

Traces the path rainwater would take across a terrain / site surface, following
the direction of steepest descent from a set of starting points — used to spot
drainage paths and pooling areas.

## File

| File | What it does |
|------|--------------|
| [`rainwater_flow.gh`](rainwater_flow.gh) | Traces flow paths across an input terrain surface or mesh. |

## Usage

1. Open in Grasshopper (Rhino 7+).
2. Reference the terrain surface / mesh.
3. Set the starting points (or sampling density) for the flow traces.

## Software

- Rhino + Grasshopper
