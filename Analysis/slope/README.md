# Slope Analysis

Analyzes a terrain / site surface for grade (slope), typically to flag
buildable vs. unbuildable zones or to color a surface by steepness.

## File

| File | What it does |
|------|--------------|
| [`slope_analysis.gh`](slope_analysis.gh) | Evaluates slope across an input terrain surface or mesh. |

## Usage

1. Open in Grasshopper (Rhino 7+).
2. Reference the terrain surface / mesh.
3. Set the slope thresholds to distinguish buildable from unbuildable areas.

## Software

- Rhino + Grasshopper
