# Ramp

Two ramp generators.

## Files

| File | What it does |
|------|--------------|
| [`ramp_with_landing.gh`](ramp_with_landing.gh) | Straight-run ramp with one or more intermediate landings. Driven by run length, rise / slope, and landing size. |
| [`spiral_ramp.gh`](spiral_ramp.gh) | Helical ramp winding around a central axis. Driven by radius, total rise, number of turns, and ramp width. |

## Usage

1. Open the definition you need in Grasshopper (Rhino 7+).
2. Set the driving dimensions (rise, run / radius, width, landing size or turns).
3. Bake the resulting ramp surface / solid.

## Software
