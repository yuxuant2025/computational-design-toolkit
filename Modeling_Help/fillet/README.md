# Fillet

Offsets a curve by a given distance and rounds the resulting corners with a
fillet radius — handy for thickening walls, generating slab edges, or cleaning
up sharp offset corners.

## File

| File | What it does |
|------|--------------|
| [`offset_fillet.gh`](offset_fillet.gh) | Offset a curve, then fillet its corners at a set radius. |

## Usage

1. Open in Grasshopper (Rhino 7+).
2. Reference the base curve.
3. Set the offset distance and fillet radius.

## Software

- Rhino + Grasshopper
