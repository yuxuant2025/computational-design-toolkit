# Diagrid

Builds a diagonal structural grid (diagrid) over a roof or shell surface by
subdividing it in UV and connecting the diagonals. Outputs the diagrid members
as lines / curves ready to give a section.

## File

| File | What it does |
|------|--------------|
| [`roof_diagrid.gh`](roof_diagrid.gh) | Diagrid member lines across a roof surface, from a UV subdivision count. |

## Usage

1. Open in Grasshopper (Rhino 7+).
2. Reference the roof surface.
3. Set the U and V division counts to control grid density.

## Software

- Rhino + Grasshopper
