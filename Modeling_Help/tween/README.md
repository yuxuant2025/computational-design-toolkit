# Tween

Generates evenly interpolated "in-between" shapes between two input curves (or
section profiles) — a tween / morph. Useful for blending between two profiles,
building transition geometry, or lofting through generated intermediates.

## File

| File | What it does |
|------|--------------|
| [`tween.gh`](tween.gh) | Takes two curves and a count, outputs the interpolated curves between them. |

## Usage

1. Open in Grasshopper (Rhino 7+).
2. Reference the two boundary curves.
3. Set the number of in-between steps.

## Software

- Rhino + Grasshopper
