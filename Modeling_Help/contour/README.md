# Contour

Slices geometry with a series of evenly spaced parallel planes and returns the
section curves — contours for terrain, waffle / rib construction, laser-cut
stacks, or drawings.

## File

| File | What it does |
|------|--------------|
| [`contour.gh`](contour.gh) | Contours an input surface / brep / mesh at a set spacing and direction. |

## Usage

1. Open in Grasshopper (Rhino 7+).
2. Reference the geometry to contour.
3. Set the contour direction and spacing.

## Software

- Rhino + Grasshopper
