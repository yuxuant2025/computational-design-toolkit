# Perforation

Distributes openings (holes) across a panel or surface, with hole size / density
driven by an attractor point, curve, or gradient. Outputs the perforated panel
and/or the cut curves.

## File

| File | What it does |
|------|--------------|
| [`perforation.gh`](perforation.gh) | Grid of openings over a surface, sized or culled by an attractor. |

## Usage

1. Open in Grasshopper (Rhino 7+).
2. Reference the panel surface and an attractor (point / curve).
3. Adjust grid spacing, min / max hole size, and attractor falloff.

## Software

- Rhino + Grasshopper
