# Block to Family

Converts Rhino block instances into Revit family instances, bridging a
Rhino/Grasshopper model into a Revit/BIM workflow.

## File

| File | What it does |
|------|--------------|
| [`block_to_family.gh`](block_to_family.gh) | Reads Rhino block instances and maps them to Revit families. |

## Usage

1. Open in Grasshopper (Rhino 7+).
2. Reference the Rhino blocks to convert.
3. Set the target Revit family / category mapping.

## Software

- Rhino + Grasshopper
- Revit (destination for the converted families)
