# Rhino to Revit

Interoperability tools that bridge a Rhino/Grasshopper model into a Revit/BIM
workflow — converting geometry and carrying parametric data across, rather
than generating or evaluating geometry on their own.

## Index

| Script | Description |
|--------|-------------|
| [block_to_family](block_to_family) | Convert Rhino block instances into Revit family instances. |
| [elefront_bake_attributes](elefront_bake_attributes) | Bake geometry with attached attributes (via Elefront) for downstream BIM use. |

## Software

- Rhino + Grasshopper
- Revit
- Elefront (plugin, required for `elefront_bake_attributes`)
